**Project Description
---------------------

1. Project Name:
=> My-Fit-Log-App

2. Description:
=> A simple website helpful in maintaining one's gym routine.
   Within two pages one can navigate and select exercises according to the user's preference, physique and diet quality. Perfect companion 
   for a day to day maintenance of personal health and building a perfect and healthy body.

3. Technologies Used:
=> i.  Font Awesome
   ii. DaisyUi
   iii.Next.js 
   iv. TailwindCSS

4. Key Features:
=> i. All available exercises are shown in the homepage library,
      from where any individual exercise's details can be seen.
   ii. A daily workout routine can be saved as a list according to    required category.
   iii.Exercises can be saved for later.
   iv. Navbar and Footer are visible in every page.
   v. Total amount of calories burned, total time required to complete the saved exercises are shown in my plan page.
